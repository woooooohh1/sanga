# v11.3 Premium Modal Refresh

- 상담 기록 팝업을 고급형 SaaS 스타일로 전면 재디자인
- 모달 헤더를 담백한 화이트 기반으로 변경하고 타이포 계층 강화
- 신청자/관심과정/신청일시 요약을 네이비 정보 스트립으로 통합
- 문의내용/상태선택/관리메모를 흰색 섹션 카드로 단순화
- 상태 선택은 과도한 색 사용을 줄이고 선택된 상태만 은은하게 강조
- 상담 메모 textarea 포커스/여백/가독성 개선
- 하단 저장 영역을 명확한 Primary/Secondary 액션 구조로 정리
- 공지/취업정보/연혁 등의 일반 CRUD 팝업도 동일한 디자인 언어로 통일
- 과정 상세 편집 팝업도 동일한 보더/라운드/여백 톤으로 보정
- 모바일에서는 바텀시트 형태 유지, sticky action bar와 safe-area 대응
