# v10 - 과정 상세 콘텐츠 보강

## 반영 내용
- 기존 6개 과정 상세페이지의 소개 문구를 실제 학원 랜딩페이지처럼 구체적으로 보강
- 각 과정별 핵심 포인트 4개 구성
- 수료 후 핵심역량 3개 구성
- 과정별 커리큘럼을 5~6단계로 세분화하고 단계별 세부 학습내용 추가
- 추천 대상 5개씩 구성
- 수강 혜택/학습 지원 3개씩 구체화
- FAQ 6개씩 구성
- 과정 목록 카드의 설명 문구와 태그도 상세페이지 내용에 맞게 보강
- 기존 v9 localStorage 데이터가 남아 있어도, 관리자가 직접 수정하지 않은 상세 콘텐츠는 v10 기본 콘텐츠가 우선 표시되도록 버전 처리
- 관리자가 상세편집 후 저장하면 이후에는 관리자 수정값을 우선 사용

## 주의
- 교육기간, 수강료, 자비부담액 등 금액/일정 값은 기존 프로젝트 값을 유지했습니다.
- 실제 운영 전에는 학원의 확정 모집 일정과 국민내일배움카드 적용 금액을 반드시 최종 확인해 주세요.
