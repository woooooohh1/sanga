# v11.0 관리자 상담 UX / 반응형 개선

- 모바일 대시보드 최근 상담신청 상태 배지가 작은 화면에서도 항상 표시되도록 레이아웃 재구성
- 350px 이하에서는 상태 배지가 별도 줄로 내려가도록 처리
- 관리자 전체 select를 커스텀 화살표/hover/focus 스타일로 통일
- 상담 상태 select는 상태별 배경/글자색 적용
- 상담신청 목록에서 인라인 textarea 편집 제거
- 상담내용은 요약 + '상담 기록' 버튼으로 변경
- 상담 기록 전용 모달 추가
  - 신청자/연락처/관심과정/신청일시 요약
  - 고객 문의내용 별도 읽기 영역
  - 대기/상담중/완료/취소 상태 선택 카드
  - 큰 상담내용/관리메모 입력 영역
  - 글자수 표시
  - 한 번의 저장으로 상태와 상담내용 동시 저장
- 모바일에서는 상담 모달이 바텀시트 형태로 동작
- 관리자 CSS/JS 캐시 버전 v11.0 갱신
