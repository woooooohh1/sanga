# v9 - 과정 상세 CMS

## 목표
관리자가 HTML/JavaScript를 수정하지 않고 과정 목록과 상세페이지 전체를 관리하도록 변경.

## 관리자 과정관리
- 과정 추가 / 상세편집 / 삭제
- 홈페이지 공개 / 비공개
- 교육기간 / 시간 / 수강료 / 지원구분 / 태그
- 상세페이지 상단 소개 / 배지 / 핵심 포인트
- 핵심 역량 반복 추가/삭제
- 커리큘럼 단계 반복 추가/삭제
- 추천 대상 반복 추가/삭제
- 수강 혜택 반복 추가/삭제
- FAQ 반복 추가/삭제
- 상세페이지 미리보기

## 공개 페이지 연동
- 관리자 저장 내용을 실업자/재직자/일반 과정 목록에 자동 반영
- 관리자에서 추가한 새 과정도 별도 HTML 생성 없이 상세페이지 제공
- 수정 내용 목록/상세에 반영
- 비공개 과정은 공개 목록에서 숨김
- 삭제한 과정 ID의 상세페이지 접근 차단
- 관리자 미리보기에서는 비공개 과정 확인 가능

## 기존 데이터 마이그레이션
기존 1~6번 과정의 `assets/course-details.js` 상세 데이터를 관리자 과정 레코드에 자동 결합하여,
기존 상세 콘텐츠를 다시 입력하지 않고 바로 관리자에서 편집할 수 있도록 구성.

## 저장소 주의
현재 프로젝트는 정적 HTML 데모 구조이므로 `localStorage`를 저장소로 사용합니다.
실제 운영 배포에서는 동일한 데이터 구조를 DB/API로 교체해야 여러 관리자와 모든 방문자에게 동일하게 반영됩니다.
