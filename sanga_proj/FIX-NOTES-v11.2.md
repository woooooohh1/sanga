# v11.2 - 모바일 상태 배지 정렬 + 팝업 시각 계층 개선

- 대시보드 모바일 카드에서 상태 배지가 카드 밖으로 밀리는 문제 수정
  - v11.1의 데스크톱 열 너비 규칙이 모바일 Grid에도 남아 있던 충돌 제거
  - 760px 이하에서 모든 대시보드 카드의 상태 열을 `max-content`로 고정
  - 과정/상담 카드 모두 동일한 내부 패딩과 상태 배지 위치 사용
- 상담 상세 팝업 리디자인
  - 헤더 포인트 라인/은은한 배경 강조
  - 신청자 요약을 독립 카드로 분리
  - 고객 문의내용, 상담상태, 상담메모를 각각 시각적 섹션으로 분리
  - 상태 선택마다 다른 컬러 인디케이터 적용
  - 모바일 바텀시트에서도 동일한 정보 계층 유지
- 일반 CRUD 팝업도 헤더와 폼 가독성 보강
- CSS/JS 캐시 버전 11.2 적용
